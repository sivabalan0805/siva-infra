# siva-infra

## Initial platform scaffold

This repository contains Python, Java, and Go health APIs, local Docker Compose orchestration, AWS ECR Terraform configuration, and a Jenkins pipeline.

Branch mapping:

- `develop` -> development
- `test` -> staging
- `main` -> production

Run the local services with `docker compose up --build`. They expose health endpoints on ports `8000`, `8080`, and `8081`.
"Backend services and core infrastructure configurations."  "Primary backend repository for infrastructure, APIs, and server-side logic."  "Source code for backend infrastructure and deployment workflows."
